# Konfigurieren von Opt-in mit Tags {#configuring-opt-in-with-launch}

Vereinfachung der Aktivierung der CX Enterprise-Lösung für das Opt-in mithilfe von Tags.

## Konfigurieren eines Opt-in-Szenarios mit Tags {#section-8aa1b58bf8374c938aa8cfdeddbad6ff}

[Tags](https://experienceleague.adobe.com/docs/experience-platform/tags/home.html?lang=de) in der Adobe Experience Platform-Datenerfassung erleichtert die Konfiguration und Einrichtung eines Opt-in-Szenarios mit Adobe-Lösungen. Sie können die Einholung von Einverständniserklärungen für Besucher zu CX Enterprise-Lösungen vereinfachen, indem Sie Analytics, Target, Audience Manager und andere oder alle ausgewählten CX Enterprise-Lösungen für das Opt-in bei Ihrem Einverständnisverwaltungssystem aktivieren.

**Konfigurieren der [!UICONTROL Experience Cloud ID Service]-Tag-Erweiterung**

Wenn die [!UICONTROL Experience Cloud ID Service] Tag-Erweiterung noch nicht installiert ist, öffnen Sie die Eigenschaft, klicken Sie auf *Erweiterungen* > *Katalog*, bewegen Sie den Mauszeiger über die [!UICONTROL Experience Cloud ID Service] Tag-Erweiterung und klicken Sie auf *Installieren*.

Um die Erweiterung zu konfigurieren, öffnen Sie den Tab *Erweiterungen* und halten den Mauszeiger über die Erweiterung. Klicken Sie dann auf *Konfigurieren*.

Weitere Referenzinformationen finden Sie im Abschnitt [!UICONTROL Experience Cloud ID Service]-Tag-Erweiterung [Übersicht](https://experienceleague.adobe.com/docs/experience-platform/tags/extensions/adobe/id-service/overview.html?lang=de) (die Erweiterung, die den Besucher-ID-Service implementiert).
